lncrna_rra_day14_cellline_loco

Leave-one-cell-line-out: for each of HAP1/K562/MDA-MB-231/THP1, a model trained on the other 3 cell lines predicts that one (HEK293FT excluded -- it's not a real cancer line, so holding it out doesn't test the same cross-cancer-cell-line generalization question). Tests generalization to an unseen cell line, not just an unseen lncRNA (contrast with the chromosome-held-out lncrna_rra_day14 challenge).
