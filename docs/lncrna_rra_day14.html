Leakage-audited de novo Day-14 prediction with no Day-7 measurements or Day-7-derived features. The ensemble combines fixed-parameter XGBoost classifiers and continuous-significance regressors over static annotations, baseline expression, Celligner PCA(70), handcrafted transcript descriptors, DNABERT-2 5-prime and 3-prime transcript-window embeddings, and a Nucleotide Transformer 5-prime embedding. The target-derived S1A column "Number of cell lines showing essentiality" is explicitly excluded. Model families and coarse rank weights were frozen using five-fold chromosome-grouped out-of-fold predictions (seed 42), with all rows for a chromosome held together. On the four scored cell lines, the frozen OOF ensemble reached AUROC 0.7233 and AUPRC 0.1935. Chromosome 1 was used only once after selection for final leaderboard evaluation.

2 @hyunhwan-bcm SVM (RBF via Nystroem-2000) + DNABERT-2 + Celligner PCA(70) + distance-to-gene 0.1851 0.7005
details

Switching model family, not more tuning. RBF SVM with class_weight="balanced", approximated by a 2000-component Nystroem feature map + linear SVM (configs/pipeline/svm_dnabert2_celligner70_dist_nystroem.yaml), C=0.1, on the same feature recipe as the previous best. No Optuna; C and kernel_approx were picked from a small hand-run grid. Verified across 4 seeds rather than a single run: AUPRC 0.1813 +/- 0.0088 (AUROC 0.6982), against the previous best config's 0.1593 +/- 0.0123. The mean clears that config's luckiest single run (0.1733) and even the worst seed (0.1682) nearly matches it, so this is not seed noise. The exact RBF kernel was both ~50x slower (198s vs 3.8s per fit) and worse (AUPRC 0.1581) -- the low-rank approximation regularizes a kernel that overfits 844 correlated embedding dimensions. Performance plateaus around 2000 components. Note this model does NOT win the cell-line-LOCO challenge, where it has the best AUROC but by far the worst AUPRC.
