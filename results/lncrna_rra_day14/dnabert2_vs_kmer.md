# DNABERT-2 embeddings vs. k-mer features (lncRNA RRA-hit, Day 14)

Can a learned DNA language-model representation of the lncRNA transcript beat raw
k-mer frequencies for the essentiality-hit classifier? Same task, dataset, chr1
hold-out split, and classifier wrappers (`lncfit.classifiers`) as the rest of
`results/lncrna_rra_day14/` — only the **features** change.

- **kmer**: transcript k-mer frequencies (`build_lncrna_features`, k=3) + cell one-hot.
- **dnabert2**: DNABERT-2-117M embedding of the **full spliced transcript** + cell
  one-hot. Full transcript = tiled into 510-token windows, each embedded, mean-pooled
  (no truncation); 768-dim. Generated by
  `scripts/embed_sequences.py --source body --window full` into
  `data/processed/dnabert2_transcript_full.npz` (not committed — 90 MB, reproducible;
  DNABERT-2 runs CPU/MPS here via the triton-check patch in that script).

All runs via `scripts/run_lncrna_classifier.py --features {kmer,dnabert2} --model ...`,
**untuned** defaults, chr1 held-out test set (2,470 records, 5.3% positive).

## Overall (held-out chr1)

| features | model | AUROC | AUPRC |
|---|---|---|---|
| — | null | 0.500 | 0.053 |
| k-mer (k=3) | logreg | 0.594 | 0.101 |
| k-mer (k=3) | xgboost | 0.605 | 0.085 |
| **dnabert2** | **logreg** | **0.638** | 0.101 |
| **dnabert2** | xgboost | 0.627 | **0.117** |

DNABERT-2 embeddings beat raw k-mers on **AUROC for both models** (logreg
0.638 vs 0.594; xgboost 0.627 vs 0.605) and give the best **AUPRC** (xgboost
0.117 vs the k-mer best of 0.101). The jump is clearest for the linear model —
logreg gains +0.044 AUROC from the embeddings — i.e. DNABERT-2's representation
is *linearly* more separable than k-mer frequencies, which is the point of a
learned representation. Trivial-baseline floor: AUROC 0.500, AUPRC 0.053.

Honest scale check: this is a **modest** improvement, not a breakthrough. Best
AUROC is still ~0.64 on a hard, ~5%-positive task; DNABERT-2 helps but doesn't
transform it. These are untuned defaults — hyperparameter tuning (as in
`tune_lncrna_xgboost.py`) could move both feature types.

## Per-cell-line, best configs

**dnabert2 + xgboost** (best AUPRC): K562 stands out again — AUROC 0.744, AUPRC
0.186 (vs 7.9% base rate). HAP1 is near chance (0.476). dnabert2 + logreg is more
uniform across cell lines (AUROC 0.54-0.69). Full per-cell-line numbers in the
run bundles under `classifier_runs/` (gitignored; regenerate with the runner).

## Reproduce

```bash
# 1. transcript sequences (issue #65) must exist:
#    data/processed/body_sequences_transcript.json
# 2. embed full transcripts with DNABERT-2:
uv run python scripts/embed_sequences.py --source body \
    --body-sequences data/processed/body_sequences_transcript.json \
    --window full --output data/processed/dnabert2_transcript_full.npz
# 3. run classifiers:
uv run python scripts/run_lncrna_classifier.py --model xgboost --features dnabert2
uv run python scripts/run_lncrna_classifier.py --model logreg  --features dnabert2
uv run python scripts/run_lncrna_classifier.py --model xgboost --features kmer --k 3
```
